# Reproducing the reported study

Use credentialed MIMIC-IV 3.1 and eICU 2.0 data matching the supplied fingerprints. Install requirements in an isolated environment; environment.json records the observed scientific runtime. CUDA was not used. Set ICU_RAW_ROOT to a directory containing extracted_mimic and extracted_eicu CSV.GZ directories. Run extract.py, then set ICU_EXTRACT_ROOT to the generated raw_extract directory and run prepare.py. Keep these generated files private.

The historical fits from models.py are needed by evaluate_locked.py solely for the paired preceding-model comparisons. Run models.py for that audit dependency. For the final model selection, run tuning_extension/run_search.py, followed by tuning_extension/evaluate_locked.py and tuning_extension/verify_extension.py. The evaluation reads a hash-verified selection lock. The original entry names are retained to preserve provenance; the main manuscript uses these final selected models throughout.

Run evaluate.py, sensitivity.py, negative_controls.py, recency_audit.py and audit.py to reconstruct the original ancillary/measurement tables needed by integrate_final_analysis.py. Then run integrate_final_analysis.py to regenerate all main model-dependent diagnostics and figures from the locked predictions. It reuses the separate eight-candidate ablations. coverage_hospital.py is imported by this integration script. Complete requirements and the immutable recorded protocols are included.

This source archive has been syntax-checked and assembled from executed analysis files. A clean end-to-end rerun from the distributed archive has not been performed. Existing caches must not be silently mixed with a new extraction or protocol. Run in an isolated new directory, retain logs, and compare aggregate outputs against Additional file 2. Patient data, predictions and fitted objects are intentionally absent. Original protocols describe the chronology; the main Methods describes the final procedure.
